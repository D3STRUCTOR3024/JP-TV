# 🏮 Tema Kino TV - Neón Japonés (キノ TV)

Un tema oscuro, elegante y con vibras cyberpunk diseñado especialmente para la aplicación Kino TV. Transforma la interfaz con un rediseño completo del logo en katakana (キノ TV) y una paleta de colores inmersiva.

## ✨ Características
* **Fondo Absoluto:** Negro puro (`#000000`) ideal para descansar la vista y destacar en pantallas OLED.
* **Acento Neón:** Morado brillante (`#E040FB`) que le da vida a los botones y selecciones.
* **Superficies y Bordes:** Tonos profundos de morado y azul oscuro para un contraste limpio y moderno.
* **Logo Personalizado:** Ícono y tipografía rediseñados en japonés usando vectores puros.

## 🚀 Cómo instalar en Kino TV
1. Abre tu aplicación de **Kino TV**.
2. Ve a la sección de **Plugins**.
3. Añade un nuevo plugin y pega el enlace directo (Raw) del archivo `kino-plugin.json` de este repositorio.
4. Finalmente, ve a **Ajustes > Apariencia** y selecciona **Japón Neón** para activarlo.
